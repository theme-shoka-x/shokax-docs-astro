瞬间（Moments）是 ShokaX 提供的轻量级动态发布功能，适合分享简短的文字、图片或状态更新，与长文博客形成互补。

## 什么是瞬间？

"瞬间"类似于微博、Twitter 的短动态形式，用来发布：

- 💬 日常吐槽和想法
- 📸 照片分享
- 🔗 链接推荐
- 📝 简短的状态更新

与博客文章不同，瞬间更轻量、更实时，没有复杂的分类和标签体系。

```bash
# 尚无专门的瞬间创建命令，可以直接创建文件
```

### 方式二：手动创建文件

在 `src/moments/` 目录下创建 `.md` 文件：

```md title="src/moments/2026-06-06-hello.md"
---
date: 2026-06-06
images:
  - "https://example.com/photo.jpg"
---

今天天气真好，出门散步拍了一张好看的天空 ☁️
```

### Frontmatter 字段

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `date` | `string`（日期） | ✅ | 发布日期。 |
| `images` | `string[]` 或 `Image` | ❌ | 附加图片，支持本地路径或远程 URL。 |

:::note
与文章不同，瞬间**不需要** `title`、`categories`、`tags` 等字段。
:::

## 访问瞬间页面

访问 `/moments/` 即可查看所有瞬间，按时间倒序排列。

### 导航栏配置

默认导航栏中已包含瞬间入口：

```ts title="src/theme.config.ts"
export default defineConfig({
  nav: [
    {
      text: "动态",
      href: "/moments/",
      icon: "i-ri-chat-quote-line",
    },
  ],
});
```

## 展示样式

瞬间以卡片形式展示：

- 每条瞬间显示发布日期和内容
- 如果有图片，会以适当的尺寸展示
- 支持分页浏览

## 在右侧边栏显示

在三栏布局中，可以在右侧附加栏显示最新一条瞬间：

```ts title="src/theme.config.ts"
export default defineConfig({
  layout: {
    mode: "three-column",
    rightSidebar: {
      recentMoments: true,         // 显示最近动态
      order: ["recentMoments", /* ...其他卡片 */],
    },
  },
});
```

## 常见问题

### Q: 瞬间和文章有什么区别？

| | 文章（Posts） | 瞬间（Moments） |
| :--- | :--- | :--- |
| 用途 | 长文写作、教程、技术分享 | 短动态、日常记录 |
| 字段 | title, categories, tags, cover 等 | date, images |
| RSS | ✅ 包含 | ❌ 不包含 |
| 搜索索引 | ✅ 可搜索 | ⚠️ 部分索引 |
| 分类归档 | ✅ 支持 | ❌ 不支持 |

### Q: 可以给瞬间添加分类吗？

当前版本不支持。瞬间的设计理念是轻量级、无结构的动态发布。如果需要分类，建议使用博客文章。

### Q: 可以不显示瞬间功能吗？

可以，从导航栏配置中移除瞬间入口即可：

```ts title="src/theme.config.ts"
export default defineConfig({
  nav: [
    // 删除或注释掉瞬间的导航项
  ],
});
```

ShokaX 提供了三种内容组织方式：归档时间线（按时间）、分类树（按主题层级）、标签云（按关键词）。三者结合使用，可以让读者从不同维度浏览你的文章。

## 归档时间线

归档页（`/archives/`）按年份和月份展示所有文章，以时间线形式呈现。

### 访问归档

- **全部归档**：`/archives/`
- **某年归档**：`/archives/2026/`
- **某月归档**：`/archives/2026/06/`

### 归档规则

- 文章按 `date` 字段的时间倒序排列
- 每年/每月下的文章自动分组
- 只包含已发布的文章（`draft: false`）
- 加密文章在归档中**正常显示标题**，但正文不可见

:::note
归档页面数据在**构建时**自动生成，添加新文章后需要重新构建。
:::

## 分类树

分类页（`/categories/`）以树形结构展示所有文章分类。

### 分类体系

ShokaX 支持 **多级分类** ，提供三层分类层级：

- **第一层**：主分类（如"技术""生活"）
- **第二层**：子分类（如"前端""后端"）
- **第三层**：细分类（如"React""数据库"）

### 如何在文章中使用分类

在文章的 frontmatter 中设置 `categories` 字段。ShokaX 支持两种方式：

#### 方式一：frontmatter 数组（推荐）

```md title="src/posts/my-post.md"
---
title: 我的文章
date: 2026-06-06
categories:
  - 技术
  - 前端
  - React
---
```

这会创建三层分类：技术 → 前端 → React。

#### 方式二：文件夹自动分类

将文章放在以分类命名的文件夹中，ShokaX 会自动应用分类：

```
src/posts/
└── 技术/
    └── 前端/
        └── React/
            └── my-post.md       # 自动获得分类：技术 > 前端 > React
```

:::note
如果同时使用 frontmatter 和文件夹分类，ShokaX 会合并两者。
:::

### 访问分类

- **全部分类**：`/categories/`
- **某个分类**：`/categories/前端/`

## 标签云

标签页（`/tags/`）以标签云形式展示所有标签，标签按使用频率显示不同大小和颜色。

### 使用标签

在文章 frontmatter 中设置 `tags` 字段：

```md title="src/posts/my-post.md"
---
title: 我的文章
date: 2026-06-06
tags:
  - Astro
  - Svelte
  - UnoCSS
---
```

### 标签云配色

标签云的颜色根据使用频率自动生成渐变。你可以自定义起止色：

```ts title="src/theme.config.ts"
export default defineConfig({
  tagCloud: {
    startColor: "var(--grey-6)",    // 低频标签颜色
    endColor: "var(--color-blue)",  // 高频标签颜色
  },
});
```

更多配置详见[标签云配置](/guides/configs/tag-cloud/)。

### 访问标签

- **全部标签**：`/tags/`
- **某个标签**：`/tags/Astro/`

## 三种方式对比

| 方式 | URL | 组织维度 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **归档** | `/archives/` | 时间（年/月） | 查看历史文章、追溯时间线 |
| **分类** | `/categories/` | 主题（层级树） | 按知识领域浏览、系统学习 |
| **标签** | `/tags/` | 关键词（云） | 快速定位相关文章、发现关联内容 |

## 常见问题

### Q: 一篇文章可以有多个分类吗？

可以。在 frontmatter 中使用数组即可：

```md
---
categories:
  - 技术
  - 教程
---
```

### Q: 分类名称区分大小写吗？

**区分**。`"React"` 和 `"react"` 会被视为两个不同的分类。建议保持统一的命名规范。

### Q: 如何在首页展示精选分类？

使用 `home.selectedCategories` 配置：

```ts title="src/theme.config.ts"
export default defineConfig({
  home: {
    selectedCategories: [
      { name: "技术" },
      { name: "生活" },
    ],
  },
});
```

详见[首页配置](/guides/configs/home/)。

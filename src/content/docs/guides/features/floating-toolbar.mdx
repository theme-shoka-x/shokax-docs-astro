---
title: 悬浮工具栏
description: 页面右下角悬浮工具栏的使用说明
---

ShokaX 在页面右下角提供了一个悬浮工具栏（Floating Toolbar），包含快速导航和常用操作按钮。

## 工具栏按钮

| 按钮 | 图标 | 功能 | 显示条件 |
| :--- | :--- | :--- | :--- |
| 返回顶部 | ↑ + 百分比 | 平滑滚动回页面顶部 | 始终显示 |
| 前往评论 | 💬 | 滚动到评论区 | 仅当页面有评论区时 |
| 音乐播放器 | 🎵 | 显示/隐藏音乐播放器 | 仅当 nyx-player 启用时 |
| 播放/暂停 | ▶ | 控制音乐播放 | 仅当 nyx-player 启用时 |
| 切换侧栏 | 📋 | 打开/关闭侧边栏 | 仅移动端（≤1023px） |

## 滚动百分比

返回顶部按钮下方显示当前页面的滚动百分比，实时反映阅读进度。

## 智能显隐

工具栏会根据滚动方向智能显示/隐藏：

- **向下滚动**：工具栏自动隐藏（淡出 + 下移）
- **向上滚动**：工具栏重新显示（淡入 + 上移）
- **页面顶部**：始终显示
- **停止滚动 180ms 后**：自动显示

## 毛玻璃效果

工具栏使用 `backdrop-filter: blur(12px)` 实现毛玻璃效果，半透明背景与页面内容融合自然。

## 自定义

如需修改工具栏样式或行为，编辑 `src/components/FloatingToolbar.svelte`。
